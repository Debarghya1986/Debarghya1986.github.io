# Adding an official CV PDF

Place your own approved PDF CV here, e.g. `Debarghya_Nandi_CV.pdf`.

In `index.html`, you can change the `Academic CV` button to point to `assets/cv/Debarghya_Nandi_CV.pdf`, or keep the button linked to the printable `cv.html` page and add a separate "Download PDF" link.

Do not upload a CV containing information you don't want public (private phone number, home address, personal identifiers, etc.).
